# Claims and Evidence Policy

**Repository:** The Allie Scenario Prompting Protocol (ASPP)  
**Maintained by:** Darren L. Allie, Azure & Verdant Vistas, LLC  
**Version:** 1.0  

---

## Purpose

This policy establishes the approved language standards for all public-facing content in this repository, including documentation, announcements, release notes, and promotional materials. The goal is to ensure that claims about ASPP accurately reflect its current evidentiary status — as a developing methodology under active validation — rather than implying peer-reviewed or externally validated conclusions that have not yet been established.

---

## Approved Language Substitutions

Use the following replacements throughout repository content wherever the stronger claim might otherwise appear:

| Avoid Saying | Use Instead |
|---|---|
| Validated methodology | Proposed methodology |
| Proven framework | Developing framework |
| Benchmark dataset | Pilot evaluation set |
| "ASPP-Bench proves…" | "ASPP-Bench is designed to test…" |
| Standards-aligned | Standards-mapped |
| Research-backed | Research-oriented |
| Established method | Methodology under validation |
| Demonstrated improvement | Intended improvement |
| Benchmark results | Planned evaluation results |

---

## Usage Notes

- **Prefer future-oriented and under-validation language** until peer-reviewed evidence, baseline comparisons, and multi-model evaluation results are complete and published.
- **Apply these substitutions consistently** across all files: README, documentation, release notes, benchmark descriptions, discussion posts, and preprint drafts.
- **Minimal edits are preferred** — replace only the specific phrase; do not rewrite surrounding context unless it also contains an unsupported claim.
- **When in doubt, qualify** — phrases like "designed to," "intended to," "under development," and "proposed" convey appropriate epistemic humility without diminishing the value of the work.
- This policy will be revisited and updated as ASPP accumulates formal evaluation results and external validation evidence.
