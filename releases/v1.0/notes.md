## Summary

Version 1.0 is the initial public release of The Allie Scenario Prompting Protocol (ASPP). This release establishes the foundational methodology, the S.C.E.N.A.R.I.O. framework, the benchmark evaluation dataset (ASPP-Bench), the 100-point evaluation rubric, and the complete preprint documentation prepared for Zenodo archiving and GitHub publication.

---

## What Is Included in v1.0

- Full protocol specification (ASPP Specification v1.0)
- S.C.E.N.A.R.I.O. framework reference document
- ASPP-Bench evaluation dataset (ASPP-SCENARIO-001)
- 100-point evaluation rubric with performance level definitions
- Anti-fabrication rule definition
- Standard ASPP prompt template
- Preprint in PDF, DOCX, and LaTeX formats
- BibTeX reference list
- Figures archive
- Zenodo upload checklist
- Citation metadata
- CC BY 4.0 license

---

## Key Decisions in v1.0

- ASPP uses a scenario-constrained, outcome-first methodology
- The S.C.E.N.A.R.I.O. acronym encodes all eight required stages
- Default output is one best actionable recommendation
- Anti-fabrication rule is mandatory and part of automatic failure conditions
- Evaluation rubric is scored out of 100 points with passing at 80
